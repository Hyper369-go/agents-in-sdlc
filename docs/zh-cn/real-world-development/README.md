通过真实场景、完整应用和共享待办事项，探索 GitHub Copilot 如何融入软件开发生命周期。你将通过迭代规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，面向桌游爱好者提供众筹服务。团队的待办事项已作为 GitHub 问题提交，随时可以开始处理。其中既有筛选和分页等功能任务，也有无障碍访问和编码标准等质量改进任务。

## 选择环境

无论你在哪里工作，都可以使用 GitHub Copilot。请选择适合你的构建环境。每个工作坊都有各自的设置步骤，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

并行运行代理会话、切换会话模式、协作使用画布，并在桌面应用中管理 GitHub 问题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 问题分配给异步代理、指导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
