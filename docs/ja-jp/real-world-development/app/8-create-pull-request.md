フィルター機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストは、すべて 1 つのブランチに保存されています。まとめてレビューし、プルリクエストを作成しましょう。星評価のプルリクエスト (PR) は自分でマージしましたが、今回は **Agent Merge** にマージのライフサイクルを管理させます。

> [!NOTE]
> 通常は、機能、指示の更新、スキルの更新、QA エージェントを、いくつかの PR に分けます。このワークショップでは手順を簡略化するため、フィルター機能と品質ワークフロー全体を 1 つのセッションとブランチにまとめ、そのすべてをこの PR に含めました。

このレッスンでは、次のことを行います。

- Agent Merge とは何か、マージのライフサイクルをどのように自動化するかを学びます。
- 機能の PR 全体と検証結果を確認します。
- レビュー後にのみ Agent Merge に許可を与え、PR がマージされたことを確認します。

## シナリオ

フィルター機能の開発では、Copilot を使って計画、実装、検証を行いました。Tailspin Toys は、開発者がマージの承認権限を保持したまま、残りの PR 作業を自動化したいと考えています。

## Agent Merge について

**Agent Merge** は、GitHub Copilot アプリでプルリクエストを取り込むために必要な残りの作業を自動化します。有効にすると、アプリのセッションがプルリクエストを確認し、CI チェックの失敗の修正、レビューコメントへの対応、必要に応じたリベースなど、マージを妨げている問題を解決します。その後、GitHub が許可した時点でマージします。バックグラウンドで実行され、アプリを再起動しても継続し、プルリクエストがマージされると自動的に停止します。

これまでは、自分で **Merge pull request** を選択していました。Agent Merge にその役割を任せることができますが、コードの編集やマージには、引き続き明示的な許可が必要です。許可する前に、許可される操作と作業内容を確認してください。

## Agent Merge を使って PR を管理する

すべてのコードを作成してレビューできたので、Agent Merge に PR のプロセスを管理させましょう。

1. エージェント選択ツールで **Default agent** を選びます。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択してプロセスを開始します。ドロップダウンから選ぶだけでは開始されません。

Agent Merge の処理が始まります。次の作業を行います。

- タイトルと説明を含むプルリクエストを作成します。
- Issue からセッションを開始した場合は、説明本文で関連する Issue を参照します。
- ターゲットブランチに対してリベースを行うか、マージコンフリクトを処理します。
- CI プロセスを監視し、すべてのチェックが成功するようにします。
- 他の開発者や Copilot コードレビューからのフィードバックがないか PR を監視し、コメントを解決するために更新します。
- すべてのチェックに成功すると、PR を自動的にマージすることもできます。

すべてのチェックに成功したら、Agent Merge に PR もマージさせましょう。

5. マージを許可する前に、PR の差分と検証結果を確認します。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. エージェントにマージを明示的に依頼します。

    ```plaintext
    Merge the PR once all required checks and approvals pass. Do not bypass repository protections.
    ```

9. 処理の進行状況を確認し、報告された問題を解決します。続行する前に、PR のステータスが **Merged** になっていることを確認します。マージ許可が有効になっていることや、エージェントが実行中であることだけでは、マージ完了の確認にはなりません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護ルールや不足している権限を回避しません。続行する前に、これらの問題を解決してください。
