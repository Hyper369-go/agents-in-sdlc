前の数回の演習では、ユーザー体験の改善と機能追加に関する 3 つのタスクを Copilot クラウドエージェントに依頼しました。クラウドエージェントは非同期かつ自律的に作業しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクを管理するためのツールがいくつかあります。そのひとつが GitHub.com の[エージェントページ][agents-page]です。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。エージェントが実行した操作を調べたり、進行中のセッションに追加のガイダンスを伝えたりできます。

このレッスンでは、次のことを行います。

- エージェントページを開き、クラウドエージェントのタスクを監視します。
- 進行中のセッションに追加機能を依頼し、作業の方向を調整します。

## シナリオ

エージェントにハイコントラストモードの作成を依頼した後、チームはライトモードも追加するとよいと考えました。サイトのスタイルを更新し、切り替え機能を追加する作業をすでに進めているため、まとめて実装するのが自然です。エージェントの作業を調整し、ハイコントラストに加えてライトモードも追加してもらいます。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたタスクの現在の状態を確認しましょう。

1. [Copilot エージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインのタスクリストを確認します。次のようなタスクが表示されます。
   - コードベースのドキュメントを更新する。
   - ゲーム変更用の API を生成する。
   - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクのひとつを選択し、Copilot が実行した操作を確認します。次のような作業が含まれます。
   - リポジトリからコードをチェックアウトする。
   - Copilot が作業する環境を作成する。
   - MCP サーバーをセットアップする。
   - 割り当てられたタスクを完了するための手順を実行する。

> [!NOTE]
> 表示される正確な手順は、Copilot の作業状況や進め方によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。PR と変更されたファイルを表示し、作業を監視できます。

## クラウドエージェントの作業を調整する

実行中のタスクを確認できたので、ハイコントラストモードの作業中にライトモードのトグルも追加するよう Copilot に依頼します。

1. ハイコントラストモードを追加しているセッションを選択します。エージェントが付けた名前や作業状況によって、タイトルは異なります。

   ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まったことを示すメッセージが表示されるまで、数分間セッションを確認します。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

   ```plaintext
   While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
   ```

   ![エージェントページで表示される、Copilot の作業中にアクティブセッションをガイドするダイアログ](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを認識し、作業に取り込む様子を確認します。

## Copilot に作業を任せる

前回と同じように、Copilot が更新されたタスクに取り組みます。メッセージを送信した時点で作業中だった手順を完了した後、新しい依頼を作業に反映します。

今回も数分かかります。その間に、これまでに学んだことを振り返りましょう。

## まとめと次のステップ

このレッスンでは、GitHub Copilot クラウドエージェントを監視してガイドするための中心的な場所である、Copilot エージェントページを確認しました。ミッションコントロールでは、実行中と完了済みのタスクを追跡し、作業内容をレビューし、進行中のタスクに追加のガイダンスを伝えたり、範囲を調整したりできます。

このレッスンでは、次のことを行いました。

- ミッションコントロールとエージェントページを使って、クラウドエージェントのタスクを監視しました。
- 進行中のセッションに追加機能を依頼しました。

Copilot がアクセシビリティ機能を完成させている間に、次は Copilot が作成したプルリクエストを[反復して改善し][next-lesson]ます。
